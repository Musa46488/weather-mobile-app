# 🌦️ Weather Mobile App

A cross-platform weather application built with Flutter that provides real-time weather information and location-based updates through a responsive mobile interface.

## 📱 Overview

The Weather Mobile App retrieves weather information from an external API and presents current conditions through a mobile-friendly Flutter interface.

Geolocation support allows weather information to be updated based on the user's location.

## ✨ Features

- Real-time weather information
- REST API integration
- Geolocation-based weather updates
- Location-aware weather data
- Responsive mobile interface
- Cross-platform Android & iOS support

## 🛠 Tech Stack

- Flutter
- Dart
- REST API
- Geolocation

## 🌐 API Integration

The application communicates with an external weather API to retrieve current weather information.

Location data is used to provide weather information relevant to the user's current location.
